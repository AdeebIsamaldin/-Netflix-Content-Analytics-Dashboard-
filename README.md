# -Netflix-Content-Analytics-Dashboard-
This project showcases an interactive Power BI dashboard for in-depth analysis of Netflix’s global content catalog. 
----
Project Description
This project showcases an interactive Power BI dashboard for in-depth analysis of Netflix’s global content catalog. Through dynamic visualizations and KPI metrics, the dashboard provides stakeholders with clear insights into platform growth, content diversity, audience segments, and regional dynamics, empowering business and marketing teams to make data-driven decisions.
----
Project Aim ::
The goal was to uncover key trends in Netflix’s movie and TV show releases, highlight top performing genres and countries, and reveal user interests by analyzing content rating and release patterns. The dashboard is designed to assist decision-makers in optimizing content curation strategies and identifying expansion opportunities.

 ----
Project Overview
1)Built a centralized, interactive Power BI dashboard to visualize and explore Netflix data spanning nearly a century (1925–2021).

2)Integrated multiple real-time insights using summary cards (Total Titles: 8,808, Locations: 749, Average Minutes Watched: 99.59 minutes).

3)Used filters and graph types—bar charts, donut charts, treemaps, and line charts—to display data by year, genre, type, rating, and country.

4)Provided accessible breakdowns of content types (Movies: 68%, TV Shows: 32%), leading genres (“International Movies” and “Dramas”), and regional production (top countries: United States, India, United Kingdom).

---
Tools & Technologies :

-Power Query (Automated data cleaning: handled missing values, standardized data types, formatted columns, split multi-value fields, removed nulls)

-Data Modeling

-Built relationships between tables (e.g., content, ratings, countries)

-Created calculated columns and measures for dynamic analysis

--
Technical Implementation
-Loaded more than 8,800 records and 749 unique location entries using Power Query for comprehensive data integration and advanced data shaping.

-Cleaned raw Netflix data: removed duplicates, filled or dropped missing values, unified genre/type fields, formatted date columns, and split multi-value entries.

-Built multiple one-to-many relationships and DAX-based measures to enable flexible, filterable visual analytics.

-Designed KPI cards, interactive country/genre filters, and year sliders for detailed exploration.

-Created fully automated refresh pipelines to keep reporting up-to-date as new content becomes available.

--
Key Features:
-KPI cards summarizing total titles (8,808), ratings (8,808), first/last releases (1925, 2021), and locations (749)

-Multi-visual layout: bar charts for category counts, donut chart for content type split, treemap for country-wise production, and trend line for annual growth.

-Interactive reporting: users can explore by genre, type, rating, release year, or producing country.

-Highlights most prolific contributors (e.g., United States: 6,720 titles, India: 2,630, UK: 960)

-Identifies dominant genres: International Movies, Drama, Comedy

----
Key Insights and Findings :

1)Content Expansion: Total titles analyzed—8,808, spanning 749 global locations.​

2)Content Split: Movies account for 68% and TV shows for 32% of the catalog.​

3)Top Categories: International Movies and Dramas are the most produced genres.​​

4)Regional Leaders: The United States leads releases (6,720 titles), followed by India and the United Kingdom.​​

5)Release Trends: Sharp growth in new releases after 2015, peaking before 2021.​​

6)Ratings: TV-Y7 is the most frequent rating, and a broad variety of ratings are represented.​
